# 价格与计费指南

> 适用版本：以当前仓库版本为准。本文示例均为演示值，不代表任何供应商官方价格。

价格配置决定用户额度如何换算为平台成本。上游官方价格、平台内部售价和用户分组倍率是三层概念，不能混为一谈。

## 一、价格配置入口

常见管理路径为 **管理端 → 设置 → 模型/倍率/价格相关配置**。不同版本可能将模型价格、结构化图片/视频/音频价格拆分为不同页面；后台接口和字段以 [`docs/openapi/api.json`](../openapi/api.json) 及当前版本 UI 为准。

修改价格后：

1. 保存配置并确认没有校验错误。
2. 重新打开模型详情，确认缓存已刷新。
3. 使用受限测试令牌调用一次。
4. 在使用日志中核对模型、渠道、Token/单位、倍率和扣费结果。
5. 生产环境变更前导出或记录旧配置，便于审计和回滚。

## 二、聊天与向量模型价格

聊天类通常按输入 Token、输出 Token、缓存命中/写入等维度计费。模型价格字段和平台倍率由当前版本的 Pricing 模型与 `ratio_setting` 配置决定，常见概念如下：

| 概念 | 含义 |
|---|---|
| ModelRatio | 模型基础倍率或模型价格换算参数 |
| CompletionRatio | 输出 Token 相对输入 Token 的倍率 |
| 缓存读取/写入价格 | 上游对缓存 Token 的单独计价 |
| 分组倍率 | 用户或业务分组的价格系数 |
| 渠道成本 | 实际选择的上游渠道和上游价格 |

不要只修改前端显示值；必须验证真实扣费日志和预扣费/结算结果。

## 三、图片、视频和音频结构化价格

仓库支持按能力配置结构化价格，例如：

- 图片：按张数、尺寸、质量或生成模式。
- 视频：按时长、分辨率、质量或任务类型。
- 音频输入：按音频时长/分钟或上游 Token 口径。
- 音频输出：按字符、时长或供应商实际计价口径。

相关运行配置包括 `ImagePricing`、`VideoPricing`、`AudioInPricing`、`AudioOutPricing`。字段名称和精确单位以当前设置页和 `ratio_setting` 实现为准；配置时必须与上游账单单位一致。

示例（仅示意）：

```json
{
  "ImagePricing": {
    "your-image-model": {
      "per_image": 0.04
    }
  },
  "VideoPricing": {
    "your-video-model": {
      "per_second": 0.02
    }
  },
  "AudioInPricing": {
    "your-asr-model": {
      "per_minute": 0.01
    }
  },
  "AudioOutPricing": {
    "your-tts-model": {
      "per_million_chars": 12
    }
  }
}
```

请勿把示例字段直接当作当前版本 API 合约；保存前以管理端实际表单和校验为准。

## 四、表达式/分层计费

动态计费和分层价格必须先阅读 [`pkg/billingexpr/expr.md`](../../pkg/billingexpr/expr.md)。重点遵循：

- 用户可控的数量、时长、分辨率、批次数必须有上限。
- 不得使用负数、NaN、Infinity 或未验证的外部 metadata 作为倍率。
- 预扣费和结算都必须使用同一套安全换算规则。
- 修改表达式后必须覆盖最小值、边界值、超限值和结算/退款场景。

## 五、汇率与内部售价

如果平台同时展示美元成本、人民币价格、充值或订阅价格，必须明确汇率快照和生效时间。不要在订单或充值记录中只保留一个未说明币种的 `Price` 字段；对账需要保留原始金额、币种、汇率和最终结算金额。

## 六、价格异常排查

| 问题 | 检查项 |
|---|---|
| 扣费为 0 | 模型价格是否存在、模型类型是否正确、渠道是否启用计费 |
| 扣费过高 | ModelRatio、CompletionRatio、分组倍率、缓存价格、单位是否重复换算 |
| 图片/视频费用异常 | 数量、秒数、分辨率和质量字段是否通过边界校验 |
| 音频费用异常 | 音频时长/字符统计是否可信，供应商返回值是否被限制 |
| 保存后不生效 | 设置缓存、模型缓存、服务重载和实际日志 |
| 预扣费与最终扣费不一致 | 对照预估 Token、实际 usage、结算/退款日志 |

价格配置本身不授予模型使用权。渠道密钥仍必须拥有上游模型权限，用户/令牌仍必须拥有对应分组和模型权限。
